# E-commerce Store — DripCode Starter

Build an online store with React and Context API. This is the starter code
for the [DripCode Build Projects](https://skill-grid-weld.vercel.app/projects/ecommerce-store) E-commerce Store project.

## What you will build

- Product catalog with category filter + detail pages
- Cart with quantity management, total, and a checkout flow

## Run it

```bash
npm install
npm run dev
```

## Files

- `src/data/products.js` — sample products (edit these, add your own)
- `src/context/CartContext.jsx` — cart state (stub — `TODO` marks the spots)
- `src/pages/` — Catalog, ProductDetail, Cart, Checkout (stubs)
- `src/App.jsx` — router wiring (stub)
